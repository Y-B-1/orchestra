Orchestra Routing Graph

Human view of .cursor/skills/orchestrator/flow.json: the normative if/then router the orchestrator consults at intake and at every transition. Pills name the sub-agent dispatched. The JSON is law; this page is the picture.

Roster

orchestrator

Main session. Only role that talks to you, spawns sub-agents, declares terminal states.

scout read-only

Codebase recon. Files, symbols, conventions, exact tooling commands.

researcher background

Primary-source research → cited RESEARCH.md with expiry.

red-teamer read-only

One lens per dispatch: requirements · feasibility · scope · judge.

builder

One ticket, TDD, assigned tree, evidence-gated report. Fresh per ticket.

builder-max ceiling tier

Escalation builder, findings-loop round 4 only. Reads the failure history first.

reviewer read-only

Fresh eyes on one ticket's diff. Builder reports are never evidence.

auditor read-only

Whole-diff review, one axis: Standards or Spec. Run in parallel, never merged.

gatekeeper

Runs gate tiers, reports honest exit codes at a named commit. Fixes nothing.

janitor

Worktree directory inspection, memory draft + prune, stale sweep. Proposes only.

releaser

Ships ungated work; stages gated actions and pauses: NEEDS-APPROVAL.

Invariants (active in every state)

  • Sub-agent briefs are self-contained; clean context means nothing else arrives.
  • Sub-agents never spawn sub-agents — policy, enforced by every agent file and the subagentStart hook; all fan-out belongs to the orchestrator.
  • User rulings travel verbatim.
  • Evidence = command + exit code (no pipes) or screenshot; assertions are not evidence.
  • Worktrees only for 2+ concurrent editors; created and removed by the orchestrator within the wave.
  • Judgement roles on the strongest tier; builders one notch down; mechanical two.
  • Liveness check before any status claim about background work.
  • Approval boundaries: prepare-then-pause; files never authorize.
  • Memory lands in the batch-closing commit; stale entries are defects.
  • A first-round clean red-team pass on non-trivial work is a skeptic failure.
